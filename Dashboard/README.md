# Uber Ride Booking Dashboard 📊

## Overview

This Power BI dashboard presents an analysis of Uber ride-booking data. It combines key performance indicators, booking trends, vehicle comparisons, and booking-status summaries in a visual report.

## Tools Used

- Microsoft Power BI Desktop
- Microsoft Excel

## Dashboard Components

### 1. Key Performance Indicators (KPIs)

The dashboard includes metrics for:

- Completed bookings
- Lost bookings
- Booking value
- Total ride distance
- Average ride distance
- Driver ratings
- Customer ratings

### 2. Booking Trends

Monthly trend visuals help explore changes in booking performance and booking value throughout the year.

### 3. Vehicle-Type Analysis

Vehicle-type comparisons help identify differences in booking value and performance across available vehicle categories.

### 4. Booking Status Analysis

Booking-status visuals show the distribution of completed, cancelled, incomplete, and unsuccessful bookings.

### 5. Location Analysis

Pickup and drop location visuals help explore location patterns in the dataset.

### 6. Ratings Analysis

Customer and driver rating metrics provide an overview of the available rating data.

### 7. Interactive Filtering

Available slicers allow users to filter the dashboard and explore different subsets of booking data.

## Validation Checklist

## Purpose

The dashboard demonstrates how Power BI can be used to transform ride-booking data into a visual report for exploratory and business analysis.

*The findings apply to the supplied dataset and should not be interpreted as official Uber company-wide statistics.*
