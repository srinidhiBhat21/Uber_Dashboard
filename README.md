# Uber Ride Booking Analysis Dashboard🚗📊

## Project Overview

This project focuses on analyzing Uber ride-booking data using Microsoft Excel and Power BI. The objective is to understand booking performance, cancellations, revenue, ride distance, vehicle types, customer and driver ratings, and pickup/drop locations through data analysis and visualization.

## Objectives

- Analyze overall ride-booking performance.
- Understand booking status and cancellation patterns.
- Explore booking value and ride distance.
- Compare performance across different vehicle types.
- Analyze monthly booking trends.
- Examine customer and driver ratings.
- Explore popular pickup and drop locations.
- Present key metrics through an interactive Power BI dashboard.

## Tools & Technologies

- Microsoft Excel — dataset exploration and preparation.
- Microsoft Power BI — dashboard development and data visualization.

## Dataset Overview

The dataset contains 150,000 records and 19 columns covering ride-booking activity from 2025.

It includes booking details, booking status, vehicle type, pickup and drop locations, cancellation information, booking value, ride distance, ratings, and payment methods.

## Dashboard Features

- KPI cards for booking performance and ride metrics.
- Monthly booking and booking-value trends.
- Booking-status distribution.
- Booking-value comparison by vehicle type.
- Pickup and drop location analysis.
- Customer and driver rating metrics.
- Interactive filters for exploring the data.

## Key Analysis Areas

1. Booking performance and status distribution.
2. Customer and driver cancellation patterns.
3. Booking value and distance analysis.
4. Vehicle-type performance comparison.
5. Monthly trends and location-based analysis.
6. Customer and driver ratings.
